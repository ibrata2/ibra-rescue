# 🔊 أصوات IBRA RESCUE

ارفع ملفات **mp3** لهذا المجلد بنفس الأسماء بالضبط (حروف صغيرة).
اللعبة تشغّل الملف الحقيقي إذا موجود، وإذا مو موجود تستخدم الصوت المولّد القديم — فتگدر تضيفها وحدة وحدة.

## شلون أرفعها؟
1. افتح https://github.com/ibrata2/ibra-rescue/tree/main/app/sounds
2. **Add file ← Upload files** واسحب الملفات.
3. **Commit changes** — وبعد ~10 دقايق تنزل نسخة جديدة بيها الأصوات (غيّر رقم الإصدار بـ package.json إذا تريد تنبيه للاعبين).

## نصائح
- صيغة **mp3**، جودة 128kbps تكفي.
- الأصوات القصيرة: أقل من ثانيتين، بدون سكوت بالبداية.
- الأصوات المستمرة (loop): 5–20 ثانية وتكون نهايتها تركب على بدايتها.
- مصادر مجانية: pixabay.com/sound-effects و freesound.org (أو سجّل صوتك وصوت أصدقائك بالعراقي 😄).

## 🚁 صوت لكل طيارة (اختياري)
| الطيارة | اسم الملف |
|---|---|
| الصغيرة | `heli_small.mp3` |
| الإسعاف | `heli_medic.mp3` |
| الشرطة | `heli_police.mp3` |
| الأخبار | `heli_news.mp3` |
| الشينوك (دوّارين) | `heli_chinook.mp3` |
| العملاقة | `heli_giant.mp3` |

- كل ملف 2–4 ثواني ويتكرر.
- أي طيارة ما إلها ملف تستخدم `heli.mp3`، واللعبة تغيّر النبرة حسب الحجم (الصغيرة أحد والعملاقة أثقل).
- يعني تگدر ترفع `heli.mp3` وحده بالبداية، وبعدين تضيف الباقي وحدة وحدة.
